### 🚀 Featured Projects

**[Voxis — Multi-Tenant Voice Dialer & Lead Intelligence Platform](https://github.com/hamaza7867)**
A multi-tenant voice-automation platform (Final Year Project) built with Django, Angular, and three Go microservices, achieving sub-400ms end-to-end voice latency.
- Twilio/Telnyx telephony with a custom WebRTC softphone — bidirectional SMS, call logging, automated routing (USA + Pakistan numbers)
- 3-tier lead discovery engine (Playwright, Go scraper, Groq AI) + an AI-powered site auditor for technical SEO/performance
- Human-to-AI conversational voice pipeline (Deepgram STT, Groq LLM, ElevenLabs TTS) with real-time BANT qualification and barge-in handling
- Async task layer: Celery, PostgreSQL, Redis — deployed as a Docker stack on AWS EC2 with GitHub Actions CI/CD

**[Voiceovers Digital — Production-Grade TTS SaaS](https://github.com/hamaza7867)**
A hyper-realistic text-to-speech platform for long-form AI narration.
- High-performance Python/Go ONNX-based microservice + Cloudflare Workers backend
- React Studio dashboard (Astro/React) converting 60–120 minute scripts into 24kHz WAV narration masters
- 54-voice catalog via a consolidated ONNX-based voice vector system for optimized I/O and runtime
- Serverless coordinator (Cloudflare Workers + D1 SQLite) for billing, auth, and job queues
